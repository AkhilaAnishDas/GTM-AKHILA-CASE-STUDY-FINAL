## Project Overview

**TailorTime** is a digital appointment platform designed for local tailoring shops. It helps customers book appointments, track their tailoring jobs, and receive notifications when their orders are ready.

The main idea is:

**Book → Track → Collect**

TailorTime aims to reduce waiting time, avoid peak-hour crowding, and make the tailoring process more organized for both customers and shop staff.

## Problem Statement

Local tailoring shops often receive many customers for measurements, fittings, alterations, and collections. This can create unpredictable queues, repeated visits, and difficulty in managing job status.

TailorTime provides a simple digital solution for managing appointments and tracking tailoring orders.

## Objectives

* Provide easy appointment booking.
* Reduce customer waiting time.
* Manage measurements and tailoring jobs.
* Track order status.
* Notify customers when orders are ready.
* Help shops manage workload and appointments.
* Improve the overall customer experience.
